# RescueMap Viewer 0.8

第一阶段目标：导入 COLMAP 生成的 PLY 点云或网格，并进行旋转、缩放、平移和基础信息查看。

界面将照片工作流明确拆分为上下两个独立模块。上方“照片预处理”先从原始照片生成
经过用户确认的最终静态图片数据集，并保存全部阶段成果；完成后软件自动把
`static_images` 路径填入下方“照片一键重建”，但不会自动开始建模，用户确认输入后再
手动启动正式重建。这样预处理结果可以单独检查、修改和复用。

预处理会按文件名排序来确定时间上的前后相邻帧。导入前应让文件名随拍摄时间递增
（例如 `0001.jpg`、`0002.jpg`、`0003.jpg`）；无需手工输入时间，但不能把文件名
随机打乱。背景恢复同时参考动态区域四周的静态像素，以及前后相邻照片经局部投影
校正后的对应区域，并以多视角一致性决定哪些像素可以写回。

0.6版新增“照片一键重建”：在同一界面中选择照片目录、工程目录和
COLMAP的 `bin\\colmap.exe`，软件会在后台依次完成特征提取、特征匹配、
稀疏重建、稠密重建、点云融合和Poisson网格生成，并自动加载结果。
每次运行都会创建独立的 `reconstruction_日期_时间` 目录，不覆盖以前的成果。

“自动抑制跨帧移动物体”开启时，软件先以较低分辨率完成一次快速稀疏重建，
比较相邻照片的原始特征匹配与几何验证内点。只有在多个相邻图像对中反复违反
极线几何、并且在图像平面上成簇出现的区域才会被判为高置信动态区域。软件据此
生成COLMAP掩膜和去动态干扰照片，再自动进行第二次正式重建。该策略不要求用户
逐张标注，并有意保留不确定区域；长时间静止的物体仍可能作为静态场景保留。

动态抑制提供保守、标准和激进三档。软件先把成簇的跨帧几何异常特征作为高置信
动态种子，再在缩放图像中依据亮度边缘进行受限区域扩张，使零散特征点覆盖到更完整
的动态物体，同时由异常特征所在栅格限制最大传播范围。保守档扩张较小，优先保留
动态物体附近仍然可见的静态地形；运行后会在本次重建目录保存
`dynamic_masks`、`dynamic_mask_previews`、`static_images` 和
`dynamic_report.json`。红色预览用于检查遮挡位置，JSON记录几何种子像素数、
区域扩张像素数、逐图掩膜比例和
几何静态可见率。若某片地形在所有照片中都被动态物体遮住，掩膜无法凭空恢复纹理，
应在三维地形阶段使用周围参考点恢复，并继续标记为预测数据。

开启动态抑制后，正式重建前会进入两次人工复核。第一次显示算法识别出的红色动态框，
左键拖动可补充漏检区域，右键单击红框内部可删除误检区域；保存后软件执行多视角静态
背景恢复。第二次直接检查恢复后的静态图片，可继续增删动态框，软件随后再次恢复并生成
最终 `static_images` 数据集。两次复核均不会修改原始照片。
最终确认只结束照片预处理，不会立即启动建模。用户可以继续返回修正动态框，也可以
在主界面再次查看最近生成的静态数据集；确认满意后，再使用下方“一键重建”。

图片处理采用逐阶段可见的确认流程。夜间增强完成后先逐张并排显示原图和增强图，用户
可以选择采用增强结果或退回原图；自动检测后显示带红框数据集；首次背景恢复后显示静态
图片供第二次框选；最终恢复完成后再次并排显示处理前和最终静态图片。用户确认最终
数据集后，软件会把它送入下方“一键重建”的照片目录，但仍由用户决定何时开始建模；
若不满意，可从最后一步返回继续修正动态框。
夜间增强、动态掩膜分析和多视角恢复等耗时步骤在后台线程中运行，主界面保持响应，
并显示一个小型处理窗口及累计耗时。阶段完成后窗口自动关闭。

对于整套照片普遍偏暗的夜间数据，可勾选“统一增强夜间/弱光照片”。软件从整个数据集
估计一组公共亮度范围，以相同的对比度和伽马映射处理全部图片并保存到
`enhanced_images`，避免逐张自动增强造成跨帧亮度跳变。该处理只能显现原图中已有的暗部
纹理，不能恢复已经欠曝丢失的信息，也可能同时放大噪声，因此默认关闭并建议与原始重建
结果进行对照。

生成动态掩膜后，软件会利用快速重建数据库中前后帧的已验证匹配，为每个动态
连通区域估计局部投影。只有至少两个无遮挡供体视角在投影后给出一致颜色时，才会
用多视角中值补入目标照片并解除该像素的COLMAP掩膜；证据不足的部分继续保持黑色
并禁止特征提取。未被动态掩膜覆盖的原始照片区域不会修改。结果保存在
`background_completion_previews` 和 `background_completion_report.json`。软件根据
遮挡边界的梯度强度自适应选择验证分支：强纹理区域要求投影后的局部纹理相关性
通过后才向遮挡内部延伸，预览显示绿色；弱纹理区域主要依靠局部投影内点率、边界
误差和多视角一致性，预览显示蓝色；红色为仍未解决的遮挡。

当前版本支持：三点校正地面坐标系、两点已知距离恢复米制尺度、可调的宽松密度分级、选择地形区域、对空白区域进行二维边界约束完全补全，以及由用户将预测区域标记为“接受、待定或补拍”。只有真实格子和人工接受的预测格子可以生成三角地形网格；预测数据不会冒充真实观测。

对于选中的空白区域，软件还可以同时生成二维边界补全、倾斜平面和稳健二次曲面
三个候选地形，并给出几何边界连续性、候选模型一致性、图像纹理强度、跨视角
灰度一致性和综合置信度。候选点会使用坐标校准矩阵的逆变换投影回COLMAP的
`dense/images`，纹理越强、有效视角越多，图像证据在总分中的权重越高；弱纹理时
自动退回以几何证据为主。动态抑制留下的黑色掩膜像素不参与图像评分。最终结果
只是软件推荐，仍由用户决定是否应用、接受或补拍。

完整场景和局部地形使用两个图层：`meshed-poisson.ply` 是完整三角网格地图，会复用 `fused.ply` 的坐标轴与米制尺度校准；Kalman生成的地形网格仅覆盖用户框选的分析区域，并作为预测补充层显示。

```powershell
cd F:\Desktop\work\rescuemap

```

打开软件后手动选择模型：

```powershell

```


## 0.3 使用顺序

1. 打开 `fused.ply`。
2. 点击“选择3个地面点，校正Z轴”，在模型中依次左键点三个地面点。
3. 如果上下颠倒，点击“翻转Z方向”。
4. 点击“选择2个点，设置真实长度”，点选已知距离的两点并输入米数。
5. 点击“选择2点确定地形矩形范围”，选择需要分析的地形范围。
6. 默认选择“二维边界约束完全补全（推荐）”，点击“生成空白区域预测”并设置栅格边长。该算法使用八邻域二维调和方程，同时受四周真实高度约束，并补全所选矩形内全部空白格。旧行列Kalman仅保留用于算法对比。
7. 在右侧逐个查看候选区域，并人工选择“接受、待定或补拍”。
   如当前加载的是保留了 `dense/sparse` 和 `dense/images` 的 `fused.ply`，可先点击
   “评价三个候选地形（几何＋图像）”，查看各候选得分，再点击“应用软件推荐候选”。
8. 使用 `Ctrl+S` 保存工程，坐标变换、范围、预测设置和人工决定都会写入工程文件。
9. 点击“生成地形网格”，设置最大连接坡度；绿色面来自真实观测，黄色面包含人工接受的预测点。最大连接坡度只筛除包含真实观测点的异常陡峭连接；完全由已接受预测点组成的连续补全面不会在建网阶段被挖空，其可通行性仍由后续路径规划的最大坡度判断。
10. 可以在带复选框的区域列表中勾选多个区域，并批量设为接受、待定或补拍。右侧栏可以滚动，各功能区点击标题可折叠。
11. 点击“导出网格”：PLY需在Blender中使用“文件 → 导入 → Stanford (.ply)”，不能使用“文件 → 打开”；VTP保留VertexSource、Confidence、FaceSource等完整字段。

生成网格后，可在“规划地形网格”区随时显示、隐藏或仅查看该图层。
也可以重新导入先前导出的 `terrain_mesh_data.vtp` 或 `terrain_mesh.ply`；
建议优先导入VTP，因为VTP会保留真实/预测来源、置信度和填充策略等字段，
后续的人员安全路径节点应当在这一规划地形表面上选择。

选中预测区域时，该区域会显示为紫色高亮。可为当前区域或复选框勾选的多个区域设置人工地形提示：自动二维补全、填平、倾斜平面、缓变曲面、上凸或下凹。填平采用周围真实高度的稳健中值；倾斜平面使用周围真实点拟合；“缓变曲面（遮挡恢复）”使用至少6个同层参考点拟合二次曲面，并以稳健残差剔除其他地表层和动态物体残留等离群点，适合具有纵坡、横坡或缓慢弯曲的地形；参考点不足时会安全退化为平面。上凸和下凹以拟合平面为基准并要求输入最大起伏强度。复杂且无法可靠判断的区域应标为补拍。

如果同一XY附近同时存在上层和下层点云，可点击“在三维地图中单击选择预测区域”，再点击“选择周围参考点，拟合目标地表”。建议在同一地表层选择6～12个参考点。参考点只用于判断目标地表的高度和走势，不会改变自动检测出的空白区域，也不会再尝试围成多边形；这样可以避免共线、重复吸附和跨层选点造成的补充范围错误。之后的填平、倾斜、上凸和下凹策略都会优先使用这组参考点。

如果自动预测区域没有覆盖完整空白，可先选择当前区域及其周围参考点，再选择填平、倾斜、上凸或下凹策略，点击“俯视框选人工补充范围”。软件会自动切换到俯视图；按住左键拖出矩形后，将在矩形覆盖的XY栅格中显式创建预测点。同一XY位置原有的错误点层会被人工补充层取代。该范围由用户明确指定，不再根据参考点自动猜测；可连续框选，按Esc完成并恢复地图旋转。

预测生成后可以直接左键单击黄色/彩色预测点选择区域，短按选择、拖动旋转。进入坐标校正、范围或参考点等连续选点功能后，使用右键添加点，左键拖动仍可旋转；按Esc或点击黄色提示栏中的“取消选点”可随时退出。补充点仍位于原始预测区域的XY栅格中心，不会覆盖区域外的真实点；选中区域还会显示半透明连续曲面，以减少透视和点大小造成的视觉误判。

需要一次选择多个区域时，点击“左键拖框，勾选多个预测区域”，再在三维视图中按住左键拖出矩形。拖动过程中会显示青色边框和半透明填充，松开后框内预测点所属区域会加入批量复选框，可连续框选；完成后点击顶部或右侧的“完成框选，恢复旋转”，也可按Esc退出。退出时软件会显式恢复轨迹球交互模式，左键可重新旋转地图。软件关闭了PyVista自带英文选点文字，改用地图右下角的紧凑中文图例，每项文字颜色与对应区域颜色一致。

## 安全路径规划

生成或导入规划地形网格后，在“安全路径规划”中依次点击“选择起点”和“选择终点”，然后在网格上左键单击。软件把网格顶点自动作为候选节点，把三角面的边作为节点连接；超过最大可通行坡度的边会被删除。其余边的代价由三维距离、坡度、重建置信度、是否来自人工接受的预测区域以及可选的`MaterialRisk`材质风险共同组成，再使用Dijkstra算法寻找总代价最小的路线。粉色粗线表示最终路线，绿色点为起点，红色点为终点；可勾选“显示自动生成的可通行节点”检查建图结果。

## 完整三维地图

完成Z轴与尺度校准后，点击“加载完整 Poisson 网格”，选择同目录下的 `meshed-poisson.ply`。软件会自动应用与点云相同的变换和真实尺度。首次加载约四百万面的模型时会生成显示简化副本，可能需要几十秒；“导出已校准的完整地图”仍然使用完整精度数据。

预测颜色：黄色为尚未判断，蓝色为人工接受，灰色为待定，红色为要求补拍。预测点是独立图层，不会写入原始 PLY。

二维边界约束算法把所有观测格子的高度作为固定条件，通过八邻域离散调和方程求解全部空白格。它不会替用户决定预测是否正确；距真实观测越远的区域仍会标记为较低置信度，并交由用户接受、待定或要求补拍。旧行列Kalman仍可用于消融对比。
