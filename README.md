# RescueMap Viewer 0.6

第一阶段目标：导入 COLMAP 生成的 PLY 点云或网格，并进行旋转、缩放、平移和基础信息查看。

0.6版新增“照片一键重建”：在同一界面中选择照片目录、工程目录和
COLMAP的 `bin\\colmap.exe`，软件会在后台依次完成特征提取、特征匹配、
稀疏重建、稠密重建、点云融合和Poisson网格生成，并自动加载结果。
每次运行都会创建独立的 `reconstruction_日期_时间` 目录，不覆盖以前的成果。

当前版本支持：三点校正地面坐标系、两点已知距离恢复米制尺度、可调的宽松密度分级、选择地形区域、对空白区域进行二维边界约束完全补全，以及由用户将预测区域标记为“接受、待定或补拍”。只有真实格子和人工接受的预测格子可以生成三角地形网格；预测数据不会冒充真实观测。

完整场景和局部地形使用两个图层：`meshed-poisson.ply` 是完整三角网格地图，会复用 `fused.ply` 的坐标轴与米制尺度校准；Kalman生成的地形网格仅覆盖用户框选的分析区域，并作为预测补充层显示。


打开软件后手动选择模型：

```powershell

```


## 0.3 使用顺序

1. 打开 `fused.ply`。
2. 点击“选择3个地面点，校正Z轴”，在模型中依次左键点三个地面点。
3. 如果上下颠倒，点击“翻转Z方向”。
4. 点击“选择2个点，设置真实长度”，点选已知距离的两点并输入米数。
5. 点击“选择2点确定地形矩形范围”，选择需要分析的地形范围。
6. 默认选择“二维边界约束完全补全（推荐）”，点击“生成空白区域预测”并设置栅格边长。该算法使用八邻域二维调和方程，同时受四周真实高度约束，并补全所选矩形内全部空白格。旧行列Kalman仅保留用于算法对比。
7. 在右侧逐个查看候选区域，并人工选择“接受、待定或补拍”。
8. 使用 `Ctrl+S` 保存工程，坐标变换、范围、预测设置和人工决定都会写入工程文件。
9. 点击“生成地形网格”，设置最大连接坡度；绿色面来自真实观测，黄色面包含人工接受的预测点。
10. 可以在带复选框的区域列表中勾选多个区域，并批量设为接受、待定或补拍。右侧栏可以滚动，各功能区点击标题可折叠。
11. 点击“导出网格”：PLY需在Blender中使用“文件 → 导入 → Stanford (.ply)”，不能使用“文件 → 打开”；VTP保留VertexSource、Confidence、FaceSource等完整字段。

生成网格后，可在“规划地形网格”区随时显示、隐藏或仅查看该图层。
也可以重新导入先前导出的 `terrain_mesh_data.vtp` 或 `terrain_mesh.ply`；
建议优先导入VTP，因为VTP会保留真实/预测来源、置信度和填充策略等字段，
后续的人员安全路径节点应当在这一规划地形表面上选择。

选中预测区域时，该区域会显示为紫色高亮。可为当前区域或复选框勾选的多个区域设置人工地形提示：自动二维补全、填平、倾斜平面、上凸或下凹。填平采用周围真实高度的稳健中值；倾斜平面使用周围真实点拟合；上凸和下凹以拟合平面为基准并要求输入最大起伏强度。复杂且无法可靠判断的区域应标为补拍。

如果同一XY附近同时存在上层和下层点云，可点击“在三维地图中单击选择预测区域”，再点击“选择周围参考点，拟合目标地表”。建议在同一地表层选择6～12个参考点。参考点只用于判断目标地表的高度和走势，不会改变自动检测出的空白区域，也不会再尝试围成多边形；这样可以避免共线、重复吸附和跨层选点造成的补充范围错误。之后的填平、倾斜、上凸和下凹策略都会优先使用这组参考点。

预测生成后可以直接左键单击黄色/彩色预测点选择区域，短按选择、拖动旋转。进入坐标校正、范围或参考点等连续选点功能后，使用右键添加点，左键拖动仍可旋转；按Esc或点击黄色提示栏中的“取消选点”可随时退出。补充点仍位于原始预测区域的XY栅格中心，不会覆盖区域外的真实点；选中区域还会显示半透明连续曲面，以减少透视和点大小造成的视觉误判。

需要一次选择多个区域时，点击“左键拖框，勾选多个预测区域”，再在三维视图中按住左键拖出矩形。拖动过程中会显示青色边框和半透明填充，松开后框内预测点所属区域会加入批量复选框，可连续框选；完成后点击顶部或右侧的“完成框选，恢复旋转”，也可按Esc退出。退出时软件会显式恢复轨迹球交互模式，左键可重新旋转地图。软件关闭了PyVista自带英文选点文字，改用地图右下角的紧凑中文图例，每项文字颜色与对应区域颜色一致。

## 安全路径规划

生成或导入规划地形网格后，在“安全路径规划”中依次点击“选择起点”和“选择终点”，然后在网格上左键单击。软件把网格顶点自动作为候选节点，把三角面的边作为节点连接；超过最大可通行坡度的边会被删除。其余边的代价由三维距离、坡度、重建置信度、是否来自人工接受的预测区域以及可选的`MaterialRisk`材质风险共同组成，再使用Dijkstra算法寻找总代价最小的路线。粉色粗线表示最终路线，绿色点为起点，红色点为终点；可勾选“显示自动生成的可通行节点”检查建图结果。

## 完整三维地图

完成Z轴与尺度校准后，点击“加载完整 Poisson 网格”，选择同目录下的 `meshed-poisson.ply`。软件会自动应用与点云相同的变换和真实尺度。首次加载约四百万面的模型时会生成显示简化副本，可能需要几十秒；“导出已校准的完整地图”仍然使用完整精度数据。

预测颜色：黄色为尚未判断，蓝色为人工接受，灰色为待定，红色为要求补拍。预测点是独立图层，不会写入原始 PLY。

二维边界约束算法把所有观测格子的高度作为固定条件，通过八邻域离散调和方程求解全部空白格。它不会替用户决定预测是否正确；距真实观测越远的区域仍会标记为较低置信度，并交由用户接受、待定或要求补拍。旧行列Kalman仍可用于消融对比。
